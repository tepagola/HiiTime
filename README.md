**HiiTime** es una aplicación web de alto rendimiento diseñada para entrenamientos HIIT, Tabata y circuitos. Elimina las distracciones y se enfoca en lo que importa: tu rendimiento.

---

## ✨ Características Principales

- **🎨 Diseño Premium "Cyber-Dark":** Interfaz de alto contraste con estética *glassmorphism* y tipografía moderna (Outfit & Space Grotesk).
- **⏱️ Visualizador de Tiempo Dinámico:** Cronómetro circular animado que proporciona una referencia visual rápida de tu progreso.
- **🔊 Sistema de Audio Inteligente:** Avisos sonoros para cambios de ejercicio, descansos y cuenta regresiva final (3-2-1).
- **📱 PWA (Progressive Web App):** Instalable en tu móvil y funciona totalmente offline.
- **💾 Persistencia Automática:** Tu rutina y progreso se guardan localmente para que nunca pierdas el ritmo, incluso si cierras la pestaña.
- **🛠️ Editor Flexible:** Mezcla ejercicios de tiempo, repeticiones y descansos con facilidad.

---

## 🚀 Tecnologías

Este proyecto ha sido desarrollado bajo una arquitectura moderna enfocada en la velocidad y la experiencia de usuario:

- **Frontend:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Estado:** [Zustand](https://github.com/pmndrs/zustand) con persistencia.
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Audio:** Web Audio API (Generación sintética sin archivos externos).
- **PWA:** `vite-plugin-pwa`

## 🛠️ Instalación y Desarrollo

Si quieres ejecutar el proyecto localmente o contribuir:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/HiiTime.git
   cd HiiTime
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
